# Benchmark results

The data behind the tables in `docs/paper-notes.md`, kept so the numbers can be checked and plotted again when
the results are written up. One Windows machine (the same one throughout); file names carry the date and the
libroadrunner version compared against. The scripts that produce them are one folder up; their own outputs there
(`benchmarks/*.json`, `*.png`) are gitignored and overwritten by every run, so finished runs are copied here.

Not kept here: the BioModels raw time courses and Jacobians (`biomodels_raw_*.json`, 190 MB and 33 MB, over
GitHub's file limit). They are regenerated by `python benchmarks/biomodels_compare.py` with the models from
`biomodels_download.py`; archive them elsewhere (for example Zenodo) when the results are published.

Timing method (`bench_scaling.py`): each load timed cold, with no other instance of the model alive (libroadrunner
reuses the compiled code of a live instance of the same SBML); simulate = median of 10 repeats after `resetAll`,
`simulate(0, 50, 501)` at each engine's default tolerances.
