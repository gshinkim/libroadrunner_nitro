# Benchmark results

The data behind the tables in `docs/paper-notes.md`, kept so the numbers can be checked and plotted again when
the results are written up. One Windows machine (the same one throughout); file names carry the date and the
libroadrunner version compared against. The scripts that produce them are one folder up; their own outputs there
(`benchmarks/*.json`, `*.png`) are gitignored and overwritten by every run, so finished runs are copied here.

| File | What | Script | Versions |
| --- | --- | --- | --- |
| `2026-11-26_scaling_chain_libroadrunner-2.9.1.json`, `.png` | Load and simulate time against chain length, reversible Michaelis-Menten chains, 10-1000 reactions | `bench_scaling.py --sweep chain --plot` | libroadrunner 2.9.1 (Tellurium), roadrunner_nitro 1.0.0rc1 |
| `2026-11-26_scaling_random_libroadrunner-2.9.1.json`, `.png` | The same for random mass-action networks: 20 species with 20-800 reactions; 10-400 species with 3 reactions each | `bench_scaling.py --sweep reactions --sweep species --plot` | libroadrunner 2.9.1, roadrunner_nitro 1.0.0rc1 |
| `2026-11-26_biomodels_compare_libroadrunner-2.11.0.json` | The 1075 curated BioModels: per-model verdicts (load, time course, Jacobian; agree / disagree / which engine fails) and per-model timings | `biomodels_compare.py --reuse` (after a run) | libroadrunner 2.11.0, roadrunner_nitro at commit 8117cbe |
| `2026-11-25_biomodels_copasi_referee.json.gz` | COPASI 4.48 time courses (0-100, 101 points, rtol 1e-10, atol 1e-14) for the 89 BioModels whose time courses disagreed, used to decide which engine was right | `biomodels_copasi_all.py out.json <models>` (runs `biomodels_copasi_tc.py` per model; needs copasi-basico, not PyPI `basico`) | COPASI 4.48 |
| `2026-11-25_sbml_test_suite_nitro.json`, `..._libroadrunner-2.11.0.json` | Per-case pass / fail on the SBML Test Suite semantic cases (commit bbcbc80) | `sbml_test_suite.py` | libroadrunner 2.11.0 |

Not kept here: the BioModels raw time courses and Jacobians (`biomodels_raw_*.json`, 190 MB and 33 MB, over
GitHub's file limit). They are regenerated by `python benchmarks/biomodels_compare.py` with the models from
`biomodels_download.py`; archive them elsewhere (for example Zenodo) when the results are published.

Timing method (`bench_scaling.py`): each load timed cold, with no other instance of the model alive (libroadrunner
reuses the compiled code of a live instance of the same SBML); simulate = median of 10 repeats after `resetAll`,
`simulate(0, 50, 501)` at each engine's default tolerances.
